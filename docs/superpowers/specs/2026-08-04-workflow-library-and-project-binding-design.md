# 工作流资产列表与项目绑定设计

## 目标

将工作流模块从“当前工作流画布页”调整为“工作流资产列表页”，并建立工作流资产、版本和项目绑定之间的清晰关系。用户可以创建业务工作流、从内置模板复制、在画布中编辑并保存版本；项目导入时可以选择适配的工作流。

## 页面与交互

### 工作流列表

工作流主页展示所有可用工作流，包括内置模板和用户工作流。列表字段包括名称、类型、业务说明、当前版本、节点数、角色数、绑定项目数和更新时间。

页面操作包括新建工作流、从模板新建、搜索、筛选、编辑、版本管理、复制、导出和归档。内置模板不可直接修改，只能复制为用户工作流；复制后的工作流完全可编辑。

### 画布编辑

点击新建或编辑后进入全屏画布。顶栏只保留返回列表、名称、草稿状态、版本、保存新版本和版本管理。节点库、角色库、工作流配置、自动布局、模拟和导出使用抽屉或悬浮工具栏，避免固定面板挤占画布空间。

画布编辑草稿不会影响当前已发布版本。保存时创建新版本；历史版本只读。恢复历史版本也创建新版本，不覆盖历史记录。

### 版本管理

版本抽屉展示版本号、创建人、创建时间、备注和变更摘要，支持选择两个版本比较节点、边、角色、策略和画布布局。导出可以针对当前版本或指定历史版本。

### 项目导入与绑定

导入项目先检测可识别的工作流文件：

1. 项目包含工作流文件时，导入工作流定义并进入绑定确认。
2. 项目不包含工作流文件时，项目仍然导入成功，但不自动绑定通用工作流。
3. 未绑定项目进入“选择工作流”步骤，可选择内置模板或已有业务工作流。
4. 没有满足需求的工作流时，提示用户先在工作流模块新建业务工作流，再返回绑定步骤。
5. 从导入流程跳转新建工作流，保存成功后回跳原项目绑定页并预选新工作流。
6. 未绑定项目可以查看项目和工作流，但不能创建 Run，Run 页面显示先绑定工作流的明确提示。

## 数据关系

工作流是软件级资产，项目绑定工作流的一个具体版本。绑定记录至少包含项目、工作流、固定版本、绑定人和绑定时间。历史 Run 永远引用创建时的工作流版本，不受后续绑定升级影响。

项目绑定默认固定当前版本。用户可以主动升级绑定到新版本，升级行为记录审计日志。工作流存在绑定或历史 Run 时只能归档，不能物理删除。

内置模板通过预置工作流记录实现，和用户创建的工作流使用同一套定义结构。模板内容可以被复制和修改，但原模板保持只读。

## 兼容与错误处理

已有项目和已有工作流版本继续可读。已有导入逻辑识别到的当前工作流继续作为项目绑定版本。无工作流文件的项目不再因为缺少文件而返回 500；导入结果明确包含“未绑定工作流”状态。不存在的工作流、已归档工作流和版本不属于该工作流的绑定请求返回可读错误。

## 验收标准

- 工作流入口首先显示列表，不直接显示某一条工作流画布。
- 新建、复制模板、编辑、保存新版本、版本对比和恢复均可完成闭环。
- 内置模板不能被直接改写，复制后可编辑。
- 无工作流文件的项目可以成功导入，并得到绑定提示。
- 项目绑定后才能创建 Run，Run 使用绑定的固定版本。
- 绑定升级不改变历史 Run 的工作流版本。
- 列表、画布、版本抽屉和导入向导在桌面窗口内不产生不必要的页面级纵向滚动。
